# Ebola 2026 Bundibugyo DRC — Model and Data Code

Computational artifacts supporting the manuscript:

> Tang S. Transmission dynamics of the 2026 Bundibugyo ebolavirus disease
> outbreak in the Democratic Republic of the Congo: a compartmental model
> with an explicit observation layer. *PLOS Computational Biology* (submitted).

**This repository contains only the model and data code.** The manuscript
LaTeX source and the PLOS submission package are NOT included here; they are
prepared separately for journal submission.

## Contents

- `code/` — Python 3 model, calibration, Monte-Carlo propagation, scenario,
  and paper-quantity scripts (`numpy`, `scipy`, `matplotlib`).
- `data/` — verified UKHSA weekly surveillance series (wk21–wk41, 2026) and
  the enumerated data-source URLs.
- `LICENSE` — MIT (code). The surveillance data are public and archived with
  Zenodo (DOI to be inserted).

## Reproduce

1. `python code/ebola_model_v3.py` — model definition and deterministic integrator.
2. `python code/v6_extended.py` — v6 calibration, propagation, scenarios.
3. `python code/_v6_paper_quantities.py` — paper quantities P1–P7.
4. `python code/_v6_paper_q123.py` — supplementary quantities Q1–Q3.

The weekly figures are regenerated by the calibration / figure scripts from
`data/weekly_series.csv`. The manuscript PDF is built separately from the
working LaTeX source with XeLaTeX; the figures and PDF are regenerable
artifacts and are intentionally not included in this code archive.

## Data availability

All inputs are public surveillance series (WHO, UKHSA, ECDC, Africa CDC,
DRC Ministry of Health). The verified weekly series is provided in
`data/weekly_series.csv`; exact retrieval URLs per data date are enumerated
in `data/sources.md` and archived with Zenodo
(DOI `10.5281/zenodo.XXXXXXX` — replace with the real deposited DOI).
